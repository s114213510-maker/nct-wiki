Shift-Left Engineering Architecture

NCT LLM Wiki 雙重小圈防錯系統流程圖

講義第 26 頁原則落實：大圈很少轉，小圈轉得很快（在離源頭最近的地方攔截錯誤）

📥 階段一：原始多源資料攝入 (Raw Sources Ingestion)
raw_sources/*.md (共5篇)
攝入 2016-2026 官方白皮書、首爾隊 Fact Check 歷程、DREAM 畢業制波折、WayV 華語開拓與 SM 3.0 改革宣告。
▼
📚 階段二：LLM Wiki 結構化知識庫構建
wiki/ (35篇 Markdown)
按「概念 (concepts)」、「分隊 (units)」、「成員 (members)」、「時間線 (timeline)」與「術語 (glossary)」自動建立完整雙向關聯索引。
▼
🔍 基礎關卡：Wiki Lint 自動化結構檢驗
scripts/lint_wiki.ps1
全面檢測 35 篇文件是否存在孤島頁面 (Inbound Links = 0)、雙向連結對稱性與 K-Pop 專屬行話辭典 (Glossary)。
🔄 小圈回溯機制 0：若發現斷鏈或孤立頁面，立即在 Wiki Markdown 層局部修復，不外溢至後續階段。
▼
🔒 第一重小圈 (Gate 1)：SSOT 唯一事實狀態一致性閘門
specs/ssot_facts.md
攔截時間線滯後與舊記憶幻覺：在生成簡報大綱前，強制抽取成員與分隊唯一事實表，鎖死每位成員的狀態標籤 (active / inactive / former) 與 2026 最新離隊年月（如 Mark 2026.04 離隊、昀昀 2026.07 離隊），禁止模型偷渡外部舊記憶。
🔄 小圈回溯機制 1：若事實核對失敗，僅退回事實表與對應成員頁修正，最多重試 3 次，禁止帶著事實錯誤生成大綱。
▼
📐 階段三：逐頁規格與量化設計 (Slide Specs Planning)
specs/slide_spec.md
產出全套 17 頁教學規格，規劃珍珠香檳綠主視覺與四大分隊專屬回歸主題風格（Fact Check / We Go Up / Turn Back Time / Steady）。
▼
⚖️ 第二重小圈 (Gate 2)：Spec 量化防破版閘門
scripts/check_gate2_spec.ps1
攔截字數超載與畫面破版：在渲染 HTML 前，以自動化腳本硬性檢查量化指標：單頁正文字數 ≤ 120 字、核心卡片 ≤ 4 張、每頁必附 [Source: ...] 標籤。
🔄 小圈回溯機制 2：若字數超載或卡片超標，僅退回該頁文字規格重寫，杜絕文字溢出 (Overflow) 破壞版面。
▼
💻 階段四：教學 HTML 簡報渲染與發布
presentation/index.html
一次性生成兼具 17 頁全息雷射科技感、回歸色彩變換、動態分頁切換與鍵盤快捷鍵支援的獨立 HTML 簡報。

⚡ 講義「小圈轉得快」效益

錯誤在上游（事實層與文字規格層）即被自動化腳本小圈攔截修復，避免「改對 A 頁、改壞 B 頁」，節省 90% 以上的大模型 Token 耗費。

🛡️ 「大圈極少轉」保證

最終 HTML 渲染階段接收到的已經是 100% 事實無誤且字數排版嚴格受控的成品，實現 Zero-Shot 零破版完美交付。
